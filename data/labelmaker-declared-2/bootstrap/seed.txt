What it is: Shipping-label codes for parcels: a zone from the postcode, a running number, and a check character.
How it is used: library-style -- exercised inside the same process, by a test that calls it. Exercised here through: Zone.of, Labeler.checkChar, Labeler.next, Labeler.isValid.

Zone.of:
In short: Zone.of maps a five-digit postcode to a zone name. The zone is determined by the sum of the postcode digits modulo seven. The postcode must be exactly five digits, otherwise an IllegalArgumentException is raised.
- Zone.of(<postcode>) returns the zone whose ordinal equals the sum of the digits of <postcode> modulo seven
  - e.g. Zone.of("00000") returned NORTH
  - e.g. Zone.of("01067") returned NORTH
  - e.g. Zone.of("10115") returned EAST
  - e.g. Zone.of("20095") returned SOUTH
  - e.g. Zone.of("50667") returned WEST
  - e.g. Zone.of("60311") returned HARBOR
  - e.g. Zone.of("00005") returned VALLEY
  - e.g. Zone.of("00006") returned SUMMIT
  - e.g. Zone.of("99999") returned WEST
  - e.g. Zone.of("00000") returned NORTH; Zone.of("10115") returned EAST; Zone.of("20095") returned SOUTH
- postcode length validation: Zone.of raised IllegalArgumentException: postcode must be exactly five digits, in each of these cases
  - postcode is null
  - postcode is not exactly five characters long
- Zone.of(<postcode>) raises IllegalArgumentException with the message "postcode must contain only digits" when any character of the five-character <postcode> is not a digit

Labeler.checkChar:
In short: Labeler.checkChar computes a check character for a seven-character body. The body must contain only uppercase letters and digits. The result is the alphabet letter at index (sum of character values times position weights) mod 19.
- Labeler.checkChar(<body>) returns the alphabet letter at index (sum of each character's value times its position's weight) mod 19, where digits are 0-9 and uppercase letters are 10-35, for a valid seven-character <body>
  - e.g. Labeler.checkChar("NO00001") returned 'N'; Labeler.checkChar("EA00001") returned 'C'; Labeler.checkChar("WE12345") returned 'J'; Labeler.checkChar("SU99999") returned 'N'; Labeler.checkChar("VA00042") returned 'N'; Labeler.checkChar("HA00099") returned 'J'; Labeler.checkChar("SO00042") returned 'R'
  - e.g. Labeler.checkChar("0000000") returned 'A'
  - e.g. Labeler.checkChar("WE12345") returned 'J'
  - e.g. Labeler.checkChar("SU99999") returned 'N'
  - e.g. Labeler.checkChar("NO00001") returned 'N'
  - e.g. Labeler.checkChar("NO00001") returned 'N'; Labeler.checkChar("EA00001") returned 'C'; Labeler.checkChar("WE12345") returned 'J'
- body length validation: Labeler.checkChar raised IllegalArgumentException: body must be exactly 7 characters, in each of these cases
  - body is null -- printed: Labeler.checkChar(null) raised IllegalArgumentException: body must be exactly 7 characters
  - body is not exactly seven characters long -- printed: Labeler.checkChar("NO0000") raised IllegalArgumentException: body must be exactly 7 characters; Labeler.checkChar("NO000012") raised IllegalArgumentException: body must be exactly 7 characters; Labeler.checkChar("") raised IllegalArgumentException: body must be exactly 7 characters ; Labeler.checkCh ...
- body character set validation: Labeler.checkChar raised IllegalArgumentException: body must contain only uppercase letters and digits, in each of these cases
  - body contains a lowercase letter
  - body contains a non-alphanumeric character

Labeler.next:
In short: Labeler.next generates a label in the format ZONE-NNNNN-C. The zone prefix is derived from the postcode, and the number starts at 00001. Each call on the same instance increments the number by one.
- label generation: Labeler.next returned "EA-<n>-C", in each of these cases
  - Labeler.next(<postcode>) returns a label with the shape ZONE-NNNNN-C, where the zone prefix is the two-letter prefix for <postcode>, the number is zero-padded to five digits starting at 00001, and the check character is the weighted check character for the body -- printed: Labeler.next("10115") returned "EA-00001-C"
  - Each Labeler instance counts independently, starting again at 00001 -- printed: Labeler.next("10115") returned "EA-00001-C"
- Each subsequent call to Labeler.next(<postcode>) on the same instance increments the running number by one

Labeler.isValid:
In short: Labeler.isValid checks if a code is well-formed. It returns true only if the zone prefix, digits, and check character are valid. It returns false if the code is null, has incorrect length, wrong dash positions, lowercase characters, or invalid characters.
- Labeler.isValid(<code>) returns true for a well-formed code whose zone prefix, five digits and check character all satisfy the rules
- label validation failure: Labeler.isValid returned false, in each of these cases
  - trailing check character does not match the weighted rule for the body
  - two-letter zone prefix does not match any known zone
  - code is not exactly ten characters long
  - dashes are not in positions 2 and 8
  - code is lowercase rather than uppercase
  - code is null
  - any of the five middle characters is not a digit
