Build an AWT application which displays which functions as a screensaver. It can be maximized and also set to 800x600 pixels. The application draws an abstract flower field where one or multiple flowers of random colors appear and disappear periodically in a randomized pattern at various positions. The application has a menu which holds a start, pause and continue option with the default being start. The start option means, that the canvas is redrawn empty and then beginning with the flower field drawing. Another part of the menu is to specify a username that is displayed during the start of the canvas. The display shows "Hello + USERNAME".
